## 📖 Sobre o projeto

**José Filho — My Multiverse** é um projeto de blog pessoal desenvolvido para reunir diferentes interesses em uma única plataforma.

A proposta é criar um espaço onde seja possível publicar artigos, compartilhar opiniões, apresentar recomendações de produtos e dividir experiências sobre assuntos que fazem parte do meu cotidiano.

Mais do que um blog tradicional, o projeto busca representar diferentes partes da minha personalidade e dos meus interesses, permitindo explorar diversos assuntos sob uma perspectiva pessoal.

O nome **My Multiverse** representa justamente essa diversidade: diferentes universos de conhecimento, ideias e interesses reunidos em um único lugar.

### 🎯 Objetivos

- Construir uma plataforma pessoal moderna e responsiva.
- Compartilhar artigos e opiniões sobre diferentes assuntos.
- Publicar recomendações de produtos e tecnologias.
- Criar um espaço para interação entre leitores.
- Desenvolver um painel administrativo para gerenciamento do conteúdo.
- Aplicar conhecimentos de desenvolvimento Front-end, Back-end e banco de dados em um projeto completo.

## ✨ Funcionalidades

### 🌐 Área pública

A plataforma contará com as seguintes páginas:

- **Home:** apresentação do projeto, categorias, artigos recentes e recomendações.
- **Artigos:** listagem dos artigos publicados, com filtros por categoria.
- **Detalhes do artigo:** página individual com conteúdo completo e área de comentários.
- **Recomendações:** catálogo de produtos organizados por categoria.
- **Detalhes do produto:** informações completas sobre cada recomendação.
- **Portfólio:** apresentação de projetos e trabalhos desenvolvidos.
- **Sobre mim:** apresentação pessoal e informações sobre o autor.
- **Login:** autenticação de usuários.
- **Cadastro:** criação de novas contas.

### 👤 Sistema de usuários

Os visitantes poderão acessar os conteúdos públicos sem precisar de uma conta.

Para participar das interações, será necessário estar autenticado.

Funcionalidades previstas:

- Criar uma conta;
- Entrar e sair da plataforma;
- Comentar em artigos;
- Comentar em recomendações de produtos;
- Responder a outros comentários;
- Curtir comentários;
- Descurtir comentários;
- Alterar ou remover a própria reação.

Cada usuário poderá manter apenas uma reação por comentário, podendo alternar entre curtida e descurtida.

### 📝 Sistema de artigos

Os artigos poderão conter:

- Título;
- Subtítulo ou descrição;
- Imagem de capa;
- Categoria;
- Data de publicação;
- Conteúdo completo;
- Imagens inseridas ao longo do texto;
- Comentários dos leitores.

O editor será baseado em **Rich Text**, permitindo criar conteúdos mais elaborados com títulos, parágrafos, listas, citações, links e imagens.

### 🛍️ Sistema de recomendações

Cada produto poderá apresentar:

- Nome;
- Descrição;
- Imagem principal;
- Galeria opcional de imagens;
- Categoria;
- Preço opcional;
- Link externo para compra;
- Data de publicação;
- Comentários dos leitores.

### 🔐 Painel administrativo

O projeto também contará com uma área administrativa para gerenciamento da plataforma.

Funcionalidades planejadas:

- Dashboard com indicadores gerais;
- Criar, editar e excluir artigos;
- Publicar artigos ou salvá-los como rascunho;
- Gerenciar recomendações de produtos;
- Organizar categorias;
- Visualizar e moderar comentários;
- Excluir comentários e respostas;
- Gerenciar usuários e permissões;
- Gerenciar informações do perfil e configurações.

## 🚀 Como executar o projeto

### Pré-requisitos

Antes de começar, é necessário ter instalado:

- [Node.js](https://nodejs.org/)
- npm (instalado junto com o Node.js)
- Git (opcional, para versionamento)

### 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entrar na pasta do projeto

```bash
cd jose-filho-project
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar em ambiente de desenvolvimento

```bash
npm run dev
```

O Vite disponibilizará um endereço local, normalmente:

```text
http://localhost:5173
```

### 5. Gerar a versão de produção

```bash
npm run build
```

### 6. Visualizar a versão de produção localmente

```bash
npm run preview
```
